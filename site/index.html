Direct vs Tandem

Same request, same orchestrator (Opus 5.5). Direct: Opus writes the code. Tandem: Opus writes one contract, a local model (qwen3.8-27b) writes, tests and repairs the code with no cloud call, and Opus gets back a one-line receipt.

Method

  • Counterbalanced pairs: three pairs per task in fresh workspaces; the arm that runs first alternates from pair to pair.
  • Same isolated setup: both arms run claude -p with no user settings, plugins or project instructions. The Tandem arm adds the MCP server in the autonomous profile and the suffix "Usa Tandem."
  • Cloud cost: total_cost_usd reported by the run, at list prices. Failed attempts are counted in the cost.
  • Success: . The evaluator is independent and neither arm sees it.
  • Test machine: Intel Core i9-9900K, AMD Radeon RX 6800 series (16 GB VRAM), Ubuntu 26.04. LM Studio 0.4.28 with the llama.cpp Vulkan runtime.
  • Local model: Qwen3.8-27B-UD-IQ3_S (unsloth GGUF, about 3 bits per weight, 12 GB), all layers on the GPU, 65,536-token context, KV cache K q8_0 / V q4_0, one session, reasoning on (1,024-token budget), temperature 0.1, up to 4,000 tokens per step.
  • Not counted in the cloud cost: local model time and power, shown as local tokens and wall time.

Full report, raw data and scripts: docs/BENCHMARKS.md and benchmarks/opus/ in the repository.
